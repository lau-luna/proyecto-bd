## Instrucciones
La aplicación de java usa gradle 9.8.2
El driver para jdbc para postgres está incluido en las dependencias, por lo que no hace falta instalar aparte.

### Compilar
Desde la carpeta raiz del proyecto:
```bash
    gradle build
```

Ejecutar
Desde la carpeta raiz del proyecto:
```bash
    gradle run
```
